# Consulta API de Filmes

## Sobre o projeto

Este projeto foi desenvolvido utilizando Flutter e Dart, com o objetivo de realizar consultas de filmes através de uma API externa chamada OMDb API.

A aplicação permite pesquisar filmes pelo nome e obter informações sobre cada resultado encontrado, utilizando os dados disponibilizados pela API.

## Funcionalidades

- Pesquisar filmes pelo nome.
- Consultar informações dos filmes através da OMDb API.
- Obter os detalhes de cada filme utilizando seu ID do IMDb.
- Transformar os dados recebidos em objetos da classe Filme.

## Tecnologias utilizadas

- Flutter
- Dart
- Visual Studio Code
- OMDb API
- Biblioteca HTTP
- JSON
